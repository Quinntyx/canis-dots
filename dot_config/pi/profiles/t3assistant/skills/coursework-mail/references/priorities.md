# Priority decisions recovered from the prior assistant

Apply these decisions to the daily report, with current private profile overrides taking
precedence over historical rules. Personal names, addresses, enrollment and residence details
belong in [private configuration](private-config.md), not this source tree.

- Surface potentially attendable talks, fairs, luncheons and programs with their actual date/time;
  course logistics/deadlines; personal action from instructors, research/lab contacts, registration,
  scholarship and financial offices. Include uncertain relevance conservatively and label it.
- Treat peer-review assignments as real course obligations, including those omitted by the feed.
  Cross-check Canvas digests against existing source-backed facts and report only new/changed items.
- Report each new grade/feedback item, with score when present. An assignment due more than two
  weeks ago without grading evidence merits a "check on this grade" suggestion, not a claim that
  it is ungraded. A score below 90% merits a suggested two-hour feedback/concept review that week.
  Keep grade evidence separate from submission and mastery. This mail path records the findings
  in the private report only; it does not update Omn or schedule the review.
- Important-person/office mail can still merit a courteous reply when a request is denied or no
  substantive action remains. Before suggesting one, check the configured sent folder narrowly
  for an actual reply to that message/thread using correspondent and subject/thread evidence.
  Mere mail to the same sender is not proof of a reply. If sent-mail access is unavailable,
  label reply status unknown. Suggest 15–30 minutes only when a reply is still owed; never send it.
- A deferred decision ("come back to this" or "ask someone") merits a suggested revisit a few days
  out, before any binding deadline, with the open question and a default half-hour estimate.
  Keep the recommendation here rather than silently creating a task.
- Package-received notices merit a suggested 15–30 minute pickup within the stated return window
  (seven days when verified by the private policy), preferably on a return trip from campus.
  Preserve the actual pickup/return deadline; mail alone does not authorize planning a trip.
- Job-match/employer blasts are low priority unless notably strong or aligned with the user's
  recorded interests in frontier language models, agents, developer tooling or research.
  Reviewed routine matches and known digests need only a private no-action classification.
- Orthodontic/payment reminders already covered by an existing obligation need no duplicate task.
  Verify the private coverage rule; surface a changed amount/deadline or uncertain coverage.
- Collectible-product drop alerts remain surface-items with the drop date. The later standing
  purchase abstention supersedes the old automatic half-hour purchase errand: propose no purchase
  action while abstention is active. Resuming purchases requires the user's updated private rule.
- Old-residence staff/resident check-ins after a move are no longer attendance obligations; a
  dangling important correspondence may still merit a courtesy reply. Use private residence and
  effective-date mappings rather than guessing from an old sender or address.

Summarize urgent actions with evidence, real deadlines and unknowns. No rule above grants sending,
replying, purchasing, unsubscribing, calendar/task writes or task-thread creation. Reviewed
low-priority mail may be marked read by the daily procedure even when omitted from the short
visible summary; its classification remains in the private report.
