# Assignment preparation

- Open the actual Canvas assignment and read its requirements, deadline, and availability.
- Locate and read the relevant PowerPoints and textbook sections in the course modules/files. Reuse existing private copies; download needed originals into the coursework project. Ask for missing materials rather than inventing their contents.
- Follow the assignment's actual launch link to Codio or its assigned environment. Use the selected persistent embedded-browser profile, defaulting to `default`.
- Identify the instructions, starter files, and required tools. Leave the environment ready for the user to work in; do not submit anything.
- For login/MFA, first request the needed credentials or code through T3 Code's `request_secret` UI and use a compatible secret-aware login tool. Hand off only when secure entry is unsupported or direct user interaction is required. Never expose credentials or export session data.
- Hand off the assignment/environment link, deadline, concise requirements, and starter-file locations.
