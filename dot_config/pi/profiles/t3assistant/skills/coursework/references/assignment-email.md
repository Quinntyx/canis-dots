# Assignment email context

Every assignment preparation, including a resumed preparation, loads
[`coursework-mail`](../../coursework-mail/SKILL.md) and selects its assignment-context branch.
Resolve course/term/assignment aliases first so the query is narrow. Related messages can already
be read; their flags/tags stay exactly as found. Reuse private source evidence and report any
access, freshness or remaining-result limitation with the preparation handoff.

This route gathers context only. The one daily email thread owns triage and read-flag changes;
assignment preparation never runs that route as a fallback or starts a second email thread.
