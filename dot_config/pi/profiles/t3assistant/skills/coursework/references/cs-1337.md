# Introductory programming platform verification

Verify the course, language, platform, and assistance policy from actual instructions. Never infer
Codio, a repository workflow, or current enrollment from a remembered course code.

- If the assignment is in Codio, use [Codio handoff](cs-2336.md).
- For another LMS/IDE, open the verified activity only under the authorized browser request, locate
  starter files and requirements, and hand the workspace to the user for graded implementation.
- For explicitly requested, policy-permitted debugging of a student attempt, use
  [student-work debugging](cs-3345.md).

End with the verified platform, deadline, access state, and remaining human work. Missing platform
or policy evidence is a specific question, not a reason to generate a guessed solution.
