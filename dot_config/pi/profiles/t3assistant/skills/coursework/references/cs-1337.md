# Introductory programming platform verification

Verify the course, language, platform, and assignment requirements from actual instructions. Never
infer Codio, a repository workflow, or current enrollment from a remembered course code.

- For a Codio browser preparation request, use [Codio handoff](cs-2336.md).
- For another LMS/IDE, open the verified activity only under the authorized browser request and
  locate starter files and requirements. Prepare the requested explanation, implementation,
  reference solution, or tests using [programming assistance](cs-3345.md), then hand off the workspace.
- For debugging an existing attempt, collect the code, observed failure, and expected behavior
  needed for diagnosis. An implementation request does not require an existing attempt.

End with the verified platform, deadline, access state, and remaining human work. Ask for missing
platform or assignment details rather than guessing a workspace or claiming an unobserved result.
