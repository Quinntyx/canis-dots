# Codio programming handoff

1. Verify the actual course and assignment through Canvas. Follow its linked Codio/external-tool
   launch in the authenticated embedded T3 browser; do not guess a workspace or activity URL.
2. Read instructions, starter materials, required language/version, grading constraints, and the
   course assistance policy. Identify the active project/activity and any access prerequisite.
3. Leave the relevant activity open for the user. Provide a short requirements checklist, relevant
   course concepts, and a description of the starter layout without implementing graded solutions.
4. The user writes the assignment code, runs the autograder and submits. If separately asked for
   permitted debugging of user-written code, switch to [student-work debugging](cs-3345.md).
5. Hand off the open tab, verified activity identity, deadline, and remaining human actions. Record
   access/authentication blockers instead of claiming that an LMS workspace is ready.

An automatically created reminder remains idle when human work is required. A browser handoff
request authorizes navigation to that activity, not platform submission or an autograder run.
