# Communication and human-authored deliverables

1. Read the actual writing/presentation assignment and current AI policy. Identify the human-owned
   deliverables, due dates, peer-review obligations, and source/disclosure requirements.
2. When generated deliverables are prohibited, provide an idle reminder and link to the instructions.
   The user drafts the written work, presentation, discussion, or peer response.
3. Under an explicitly permitted request, explain general communication concepts using unrelated
   examples; keep generated prose separate from deliverables and honor the actual policy.
4. Recurring textbook quizzes and peer reviews can come from Omn without any Canvas entry.
   For KHPContent, use the coordinator's occurrence-specific deadline, exceptions and source
   artifacts; open the existing authorized LMS for a human handoff. Never treat a preparation-day
   recurrence as the submission deadline, invent a later quiz, or take the assessment. Check the
   syllabus when dates are unverified. Every preparation also follows
   [assignment email context](assignment-email.md) to check related read and unread messages.
5. Record the verified remaining human action and learning/practice goal. Leave submission and
   attendance confirmation to the user.
