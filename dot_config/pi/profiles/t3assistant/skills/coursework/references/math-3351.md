# Mathematical preparation

1. Verify the actual assignment and requested deliverables through the parent procedure. Identify
   the assigned problems, relevant prerequisites, and desired guide or reference-answer format.
2. Obtain the actual assigned slides and textbook sections. Build a concise conceptual map:
   definitions, theorem hypotheses, connections, and the methods each problem appears to exercise.
   Cite slide/page/section references; label missing sources and uncertainty.
3. Create `conceptual-guide.md` with prerequisite checks and analogous worked examples. Preserve
   a place for the student's independent attempt; ask a small transfer question after each example.
4. When requested, create a separately labeled `reference-answers` document so the user can choose
   when to compare. Show reasoning, assumptions, and checks, not only final numbers.
5. Prepare an empty student answer sheet using prior private LaTeX conventions when useful. Verify
   any rendered PDF opens and contains visible content. Final selection and submission stay human.
6. Record unresolved concepts and a concrete independent practice task in the learning-debt fields.
   A worked solution is useful preparation, not evidence of independent mastery.

For a timed assessment, preserve its verified access window and hand off the live activity to the
user. Requested study materials remain separate from starting or submitting that activity.
