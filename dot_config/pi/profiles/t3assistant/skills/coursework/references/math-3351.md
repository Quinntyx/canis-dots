# Mathematical preparation when assistance is permitted

1. Verify the current syllabus and assignment policy through the parent procedure. Determine
   whether assignment-specific reference answers and AI assistance are allowed and what disclosure
   and student-authored final work are required.
2. Obtain the actual assigned slides and textbook sections. Build a concise conceptual map:
   definitions, theorem hypotheses, connections, and the methods each problem appears to exercise.
   Cite slide/page/section references; label missing sources and uncertainty.
3. Create `conceptual-guide.md` with prerequisite checks and analogous worked examples. Preserve
   a place for the student's independent attempt; ask a small transfer question after each example.
4. If permitted and requested, create a separately labeled `reference-answers` document so the
   user can choose when to compare. Show reasoning, assumptions, and checks, not only final numbers.
   Use the course's disclosure requirements and keep reference material separate from final work.
5. Prepare an empty student answer sheet using prior private LaTeX conventions. Verify any rendered
   PDF opens and contains visible content. The human authors the submitted version and submits it.
6. Record unresolved concepts and a concrete independent practice task in the learning-debt fields.
   A worked solution is useful preparation, not evidence of independent mastery.

If the policy permits general study but not assigned answers, use [concept-only study](cs-3341.md).
Exams and restricted assessment windows end in a human-work handoff.
