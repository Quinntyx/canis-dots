# Physics lab preparation

1. Verify the actual lab instructions, attendance/window requirements, safety guidance, and assistance
   policy. Determine which measurements, observations and interpretations the student must produce.
2. Prepare a source-linked equipment/procedure checklist and an empty data table or report template
   when permitted. Explain relevant physics and uncertainty analysis with clearly synthetic examples.
3. Record measured data only from the student's actual observations or explicitly supplied files.
   Preserve units, provenance and raw values; never fabricate measurements or attendance.
4. The student performs the lab, writes policy-restricted analysis and submits. Hand off time-fixed
   or locked activities with their verified access window rather than attempting them autonomously.
5. Record unresolved experimental/conceptual questions as learning debt separately from submission.
