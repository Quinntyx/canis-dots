# Physics homework and restricted assessments

1. Verify the actual course offering, topic, assessment type, and assistance policy. Separate
   homework from timed quizzes, exams, in-class attendance and fixed participation windows.
2. Human-only assessments end with an idle reminder, verified access window and activity link.
3. For permitted homework study, use actual slides/textbook to identify governing laws, assumptions,
   diagrams, units and limiting cases. Prepare analogous examples and independent checks before
   any separately requested, permitted reference answers.
4. Reuse the [mathematical preparation](math-3351.md) artifact pattern, keeping the final student
   answer sheet separate. For experimental work use the [lab route](phys-2126.md).

Do not infer an assignment's availability or current enrollment from the feed or a course number.
