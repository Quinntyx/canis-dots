# Quantitative and probability/statistics preparation

1. Read the actual assignment, supplied data, and relevant slides/textbook sections. Identify the
   definitions, assumptions, distributions, and methods needed for the requested work.
2. Explain the reasoning with worked examples and checks. When requested, prepare a separate
   reference-answer sheet showing derivations, assumptions, and numerical or limiting-case checks.
3. Give an independent practice question and an observable self-check. Keep practice and conceptual
   notes separate from reference answers; record remaining conceptual gaps and a review date.
4. Cite actual source sections and distinguish supplied observations from synthetic example data.
   Ask for missing inputs rather than inventing evidence or claiming an unobserved result.

Use the [mathematical preparation](math-3351.md) artifact pattern as appropriate. Submission and
learning completion remain separate: a submission or grade never proves independent mastery.
