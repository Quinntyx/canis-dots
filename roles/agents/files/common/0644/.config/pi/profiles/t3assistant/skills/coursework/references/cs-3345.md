# Programming assistance, debugging, and testing

1. Establish the assignment requirements, language/platform, and requested help: explanation,
   implementation, reference solution, debugging, or tests. For debugging, obtain the relevant
   attempt, observed failure, and expected behavior; other help need not start with existing code.
2. Explain the design or defect and prepare the requested code or diagnostic experiment. Follow
   starter interfaces and required tooling, and include reasoning and focused checks.
3. Run checks only when execution is authorized and available. Report the actual result or the
   exact untested boundary; do not claim an autograder, grading, or submission success.
4. Keep reference code and explanations distinct from the user's independent attempt. Record a
   remaining independent practice step and any unresolved design or debugging concepts.

Keep separately requested reference material distinct from a live Codio activity; browser
preparation leaves that activity ready for the user to code, run the autograder, and submit.
